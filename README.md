# ATM-Machine
ATM Machine System

A responsive and interactive ATM Machine project developed using HTML, CSS, JavaScript, and TypeScript. This project simulates real ATM functionalities such as PIN authentication, balance inquiry, cash withdrawal, and deposit operations with a clean and user-friendly interface.

📌 Project Overview

The ATM Machine System is a frontend-based banking simulation project that demonstrates how ATM software works in real life. It allows users to securely access their account and perform banking operations through an interactive interface.

This project is designed to strengthen frontend development skills, improve programming logic, and provide practical experience with TypeScript and JavaScript functionality.

⚙️ How It Works
User enters the ATM PIN.
System verifies the authentication.
After successful login, ATM options appear.
User can:
Check Balance
Withdraw Cash
Deposit Money
View Transaction Details
Account balance updates automatically after each transaction.
User can securely exit the system.
